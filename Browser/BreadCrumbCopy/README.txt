================================================================
 要素の経路コピー コマンド 解説
 (Chrome DevTools コンソール用)
================================================================

----------------------------------------------------------------
1. このコマンドでできること
----------------------------------------------------------------

Chrome の DevTools(検証ツール)の Elements パネルで選んでいる要素について、
ページの body から、その要素までの「経路」を、タグ名・id・クラス付きの
文字列にしてクリップボードにコピーします。

出力例:

  body.is-desktop > main.is-i18n > div#jobsearch-Main > ul.list > li.item

Chrome 標準の右クリック →「Copy」→「Copy selector」や「Copy full XPath」では、
途中のクラス名が省かれたり、タグ名と番号だけになったりします。
「クラスも id も全部付いた、上からの全経路」を取りたいときに使います。


----------------------------------------------------------------
2. コード全文
----------------------------------------------------------------

(() => {
  let el = $0, parts = [];
  while (el && el.nodeType === 1 && el !== document.documentElement) {
    let s = el.tagName.toLowerCase();
    if (el.id) s += '#' + el.id;
    if (el.classList.length) s += '.' + [...el.classList].join('.');
    parts.unshift(s);
    el = el.parentElement;
  }
  copy(parts.join(' > '));
})();


----------------------------------------------------------------
3. 使い方
----------------------------------------------------------------

■ その場で使う場合

  1. 調べたいページで F12(Mac は Cmd+Option+I)を押して DevTools を開く
  2. Elements タブで、経路を知りたい要素をクリックして選択する
     (ページ上で右クリック →「検証」でもその要素が選ばれた状態になる)
  3. Console タブに切り替える
  4. 上のコードを貼り付けて Enter
  5. クリップボードに経路が入っているので、好きな場所に貼り付ける

  ※ 初めてコンソールに貼り付けるとき、Chrome が
     「allow pasting」と入力するよう求めることがあります。
     その場合は指示どおり allow pasting と入力して Enter し、
     もう一度貼り付けてください。

■ スニペットとして保存して使う場合(おすすめ)

  1. DevTools の Sources タブ → 左の欄の「Snippets」
  2. 「+ New snippet」で新規作成し、名前を付ける(例: 経路コピー)
  3. コードを貼り付けて Ctrl+S(Mac は Cmd+S)で保存
  4. 以後は、Elements で要素を選んだ状態で
     Ctrl+P(Mac は Cmd+P)→「!経路コピー」と入力して Enter
     で実行できる


----------------------------------------------------------------
4. 1行ずつの解説
----------------------------------------------------------------

【1行目】 (() => {

  「アロー関数を作って、その場ですぐ実行する」書き方の始まりです。
  最終行の })(); と対になっています。

  こう書く理由:
  中で作った変数(el や parts)が、この括弧の外に漏れません。
  コンソールで let を使って変数をそのまま作ると、
  同じコマンドを2回目に実行したとき
  「Identifier 'el' has already been declared(すでに宣言されています)」
  というエラーになります。関数の中に閉じ込めておけば、
  何度実行しても毎回まっさらな状態から動きます。


【2行目】 let el = $0, parts = [];

  変数を2つ用意しています。

  ・el
    「今見ている要素」を入れる変数です。
    最初は $0、つまり Elements で選択中の要素が入ります。
    この後のループで、親 → そのまた親 … と入れ替わっていくので、
    後から書き換えられる let を使っています(const だと書き換え不可)。

  ・$0
    DevTools のコンソールだけで使える特別な変数で、
    「Elements パネルで今選択している要素」を指します。
    ちなみに $1 は1つ前に選んでいた要素、$2 はその前 … と続きます。
    普通の Web ページのプログラムの中では使えません。

  ・parts
    経路の部品(div#xxx.yyy のような文字列)を
    順番にためていく空の配列です。


【3行目】 while (el && el.nodeType === 1 && el !== document.documentElement) {

  条件が成り立っている間、{ } の中を繰り返します。
  3つの条件を && (かつ)でつないでいて、全部満たすときだけ続きます。

  ・el
    要素が存在するか。一番上までたどって親がなくなると
    el は null になり、ここで止まります。
    また、要素を何も選ばずに実行した場合も $0 が空なので、
    すぐに終わります(エラーにならないための安全装置)。

  ・el.nodeType === 1
    それが「要素(タグ)」であるか。
    DOM には要素のほかに、文字(テキスト、nodeType は 3)や
    コメント(nodeType は 8)などもあります。
    要素だけを経路に入れるための確認です。

  ・el !== document.documentElement
    document.documentElement は <html> 要素のことです。
    <html> まで来たらそこで止め、経路には入れません。
    経路は body から始まれば十分なので、省いています。


【4行目】 let s = el.tagName.toLowerCase();

  今の要素のタグ名を取り出し、部品の土台にします。
  tagName は "DIV" "SPAN" のように大文字で返ってくるので、
  toLowerCase() で "div" "span" と小文字にそろえています。
  (CSS のセレクタでは小文字で書くのが一般的なため)


【5行目】 if (el.id) s += '#' + el.id;

  要素に id があれば、# を付けて後ろに足します。

    例: div → div#jobsearch-Main

  id がない要素では el.id は空文字 "" になり、
  if の条件が「偽」とみなされるので何も足されません。
  CSS で id を表す記号が # なので、それに合わせています。


【6行目】 if (el.classList.length) s += '.' + [...el.classList].join('.');

  要素にクラスがあれば、全部を . でつないで後ろに足します。

  ・el.classList
    その要素に付いているクラスの一覧です。
    class="cardOutline tapItem result" なら
    cardOutline, tapItem, result の3つが入っています。

  ・el.classList.length
    クラスの数です。0 なら「偽」とみなされ、何も足されません。

  ・[...el.classList]
    classList は配列に似ていますが本物の配列ではないため、
    join などの配列の機能が使えません。
    ... (スプレッド構文)で中身を広げて [ ] で包むと、
    普通の配列に変わります。

  ・.join('.')
    配列の中身を . でつないで1つの文字列にします。
    cardOutline.tapItem.result のようになります。

  ・先頭の '.' +
    join は「間」にしか . を入れないので、
    最初のクラスの前にも . が付くよう、手前で1つ足しています。

    例: li → li.css-1ac2h1w.eu4oa1w0


【7行目】 parts.unshift(s);

  出来上がった部品を、配列の「先頭」に入れます。

  このコマンドは、選んだ要素(一番下)から始めて、
  親へ親へと上に向かってたどっています。
  先頭に入れていくと、後から見つけた上の要素ほど前に来るので、
  最終的に「上 → 下」の正しい順番に並びます。

    1回目: [span]
    2回目: [div, span]
    3回目: [ul, div, span]
    …

  もし末尾に足す push を使うと、[span, div, ul …] と
  子から親への逆順になってしまいます。


【8行目】 el = el.parentElement;

  今の要素の「親要素」に移ります。
  ここで el が書き換わり、3行目の while の条件判定に戻って、
  親について同じ処理を繰り返します。
  parentElement は、親がいない(または親が要素でない)場合 null を返すので、
  そのときは while の最初の条件 el で止まります。


【9行目】 }

  while の繰り返しの終わりです。


【10行目】 copy(parts.join(' > '));

  ・parts.join(' > ')
    ためた部品を " > " でつないで、1本の文字列にします。
    CSS の > は「直下の子要素」を表す記号なので、
    出来上がった文字列はそのまま CSS セレクタとしても通用する形です。

  ・copy( … )
    文字列をクリップボードにコピーします。
    これも $0 と同じく、DevTools のコンソールだけで使える機能です。
    実行してもコンソールには何も表示されません(undefined と出るだけ)が、
    クリップボードには入っています。


【11行目】 })();

  1行目で作った関数の終わりと、それを今すぐ実行する () です。


----------------------------------------------------------------
5. 動きの例
----------------------------------------------------------------

次のような HTML があり、Elements で <span> を選んだとします。

  <html>
    <body class="page">
      <div id="main">
        <ul class="list">
          <li class="item new">
            <span>時給 1,100円</span>
          </li>
        </ul>
      </div>
    </body>
  </html>

ループの進み方:

  回数 | el      | 作られる部品     | parts の中身
  -----+---------+------------------+-------------------------------------
   1   | span    | span             | [span]
   2   | li      | li.item.new      | [li.item.new, span]
   3   | ul      | ul.list          | [ul.list, li.item.new, span]
   4   | div     | div#main         | [div#main, ul.list, li.item.new, span]
   5   | body    | body.page        | [body.page, div#main, ul.list, ...]
   -   | html    | (条件で止まる)   |

コピーされる文字列:

  body.page > div#main > ul.list > li.item.new > span


----------------------------------------------------------------
6. 注意点
----------------------------------------------------------------

■ 自動生成のクラス名は変わることがある
  css-zydy3i や eu4oa1w0 のような意味のない英数字のクラスは、
  サイトのツールが自動で付けたもので、サイトが更新されると
  別の名前に変わることがあります。
  この経路をプログラムで要素を探すのに使う場合は、
  cardOutline や salary-snippet-container のような
  意味のある名前の部分だけを使うほうが長持ちします。

■ 「何番目か」の情報は入らない
  同じタグ・同じクラスの兄弟要素が並んでいると、
  経路だけではそのうちのどれかを区別できません。
  たとえば求人カードの li はどれも同じクラスなので、
  この経路を document.querySelector に渡すと、
  一番最初のカードが選ばれます。
  (「全部のカードの同じ場所」を取りたい場合には、
   逆にこの性質が便利です)

■ 特殊な文字を含む id やクラス
  id やクラスに : や / などの記号、数字始まりの名前が含まれていると、
  コピーした経路をそのまま CSS セレクタとして使ったときに
  エラーになることがあります。人が読む用途なら問題ありません。

■ 枠(iframe)や Shadow DOM の中の要素
  ページの中に埋め込まれた別ページ(iframe)や、
  Shadow DOM という仕組みで閉じられた部品の中の要素は、
  その枠の境目で経路が止まります。
  枠の外側までつながった経路にはなりません。

■ コンソール専用
  $0 と copy() は DevTools のコンソール(とスニペット)だけで使える機能です。
  Web ページに組み込むプログラムや、ほかのブラウザでは動きません。
  (Firefox や Edge の開発者ツールにも同じ名前の機能はありますが、
   動作は各ブラウザに準じます)


----------------------------------------------------------------
7. うまくいかないとき
----------------------------------------------------------------

■ 何も貼り付けられない / 空っぽになる
  → Elements で要素を選択していない可能性があります。
    要素をクリックして選んでから、もう一度実行してください。

■ 前にコピーした内容が貼り付けられる
  → コンソールにエラーが出ていないか確認してください。
    エラーで途中で止まると、copy() まで届きません。

■ 「copy is not defined」と出る
  → DevTools のコンソール以外(ページのアドレスバーやブックマークなど)で
    実行しています。コンソールかスニペットから実行してください。

■ 貼り付け時に警告が出て入力できない
  → 「allow pasting」と入力して Enter してから、もう一度貼り付けてください。


----------------------------------------------------------------
8. ちょっとした応用
----------------------------------------------------------------

■ 決まった親のところで止めたい
  while の中の el = el.parentElement; の手前に、次の1行を足します。
  'mosaic-provider-jobcards' の部分を止めたい親の id に変えてください。

    if (el.id === 'mosaic-provider-jobcards') break;

  その親から下だけの短い経路になります。

■ 自動生成っぽいクラスを外したい
  6行目を次のように変えると、css- で始まるクラスや、
  数字が混ざった6〜10文字の英数字だけのクラス(eu4oa1w0 など)を除けます。
  result や desktop のような数字を含まない普通の単語は残ります。
  ただし heading6 のように、意味のある名前でも数字が入っていると
  消えてしまうことがあります。完全ではないので、出力を見て調整してください。

    const cls = [...el.classList].filter(c =>
      !/^css-/.test(c) && !/^(?=.*\d)[a-z0-9]{6,10}$/.test(c)
    );
    if (cls.length) s += '.' + cls.join('.');

■ 1段ずつ改行して見やすくしたい
  10行目の ' > ' を '\n> ' に変えると、1行に1段ずつ並びます。

    copy(parts.join('\n> '));
